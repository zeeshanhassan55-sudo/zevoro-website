# Zevoro website

Static website for Zevoro, an independent mobile game and app studio in Lahore.

Pages: Home, Games, Apps, About, Contact. Plain HTML, CSS and JavaScript, no build step needed to host it.

## Editing content

Page HTML is generated by `tools/gen.py`. Edit the text and data in that file, then run:

```
python3 tools/gen.py
```

Styles live in `styles.css`; theme toggle, game filters and the contact form live in `main.js`.

## Hosting

Any static host works (GitHub Pages, Netlify, Vercel, Cloudflare Pages). For GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
